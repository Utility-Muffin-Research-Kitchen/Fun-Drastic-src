# brick — TrimUI Brick / Smart Pro (NextUI)

A second worked target beside `leaf`: 64-bit (aarch64), 1024x768, NextUI CFW.
It ships the shared defaults (`shared/` launcher, config, assets). Drop either
of these here to customise it:

- `launch.sh`            — a device-specific launcher override
- `config/drastic.cfg`   — a device-specific button map (must be a FULL cfg)

Build: `make brick` / `build.bat brick`.  Package: `make pack-brick` /
`pack.bat brick`. See [../../CONTRIBUTING.md](../../CONTRIBUTING.md).
